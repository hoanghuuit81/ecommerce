# Ecommerce

Laravel REST API and React + TypeScript frontend, running with Docker Compose.

## Start

```powershell
docker compose up -d
```

- React: http://localhost:5173
- Laravel: http://localhost:8080
- API health check: http://localhost:8080/api/health
- MySQL from Windows: `127.0.0.1:3307`

## Stop

```powershell
docker compose down
```
